# 지인 플레이테스트 안내

> 스포일러 없음. 아래 "테스터에게 보낼 안내문"은 그대로 복사해 보내도 된다.
> 최종 확인: 2026-10-11 (온라인 방 + Vivox 음성 2인 검증 완료)

## 1. 준비 (호스트 = 나)

1. **빌드를 최신으로 만든다.** 코드를 고친 뒤에는 테스터와 내 버전이 같아야 접속된다.
   - Unity: **File > Build Profiles** → Windows → **Build** → 출력 폴더 `Builds/Win64/`
   - 또는 Claude에게 "빌드해 줘"
2. **`Builds/Win64` 폴더를 통째로 압축**한다 (`MurderMystery.exe`만 보내면 실행되지 않음).
   - 약 560MB (김명관 고택·한복 포함). 구글 드라이브 등에 올리고 링크를 보낸다.
   - 빌드하려면 이 PC에 KHS 에셋(`Assets/ThirdParty/KHS/`)이 있어야 한다 (git에는 없음, asset_plan.md 2절).
   - `Builds/`는 git에 올라가지 않는다.
3. Unity Cloud 연결·Vivox·Relay는 이미 켜져 있다 (프로젝트 `MurderMistery3D`). 무료 사용량 안이면 따로 할 일 없음.

## 2. 진행 (호스트)

1. Unity에서 `Assets/_Project/Scenes/Title.unity`(시작 화면)를 열고 **Play**. (빌드 exe로 호스트해도 된다)
2. 아무 키 → **사건 고르기** → "윤 대감 댁의 마지막 밤" 카드 → **방 열기** → 연결 "인터넷" → **방 열기**.
3. 고택 마당에서 화면 위의 **초대 코드(6자리, 복사 버튼)**를 테스터들에게 알린다.
4. 각자 인물 카드에서 **이 인물로**. 고르면 카드가 접히고 마당을 둘러볼 수 있다(다시 고르기 버튼 있음).
5. 전원이 고르면 호스트가 **배역 마감하고 시작**. 이후 단계는 시간이 다 되거나 **전원이 수첩(Tab)에서 "준비"**를 누르면 넘어간다.
6. 끝나면 오른쪽 위 **방 나가기 / 메뉴로 나가기**(Esc로 커서를 풀면 보임). 호스트가 나가면 방이 닫히고 모두 시작 화면으로 돌아간다.

- 혼자 둘러보기: 사건 카드의 **혼자 둘러보기**(오프라인, 1~5로 인물 전환, N 다음 단계).
- 설정(이름·마우스 감도·소리·음성)은 메인 메뉴의 **설정**.

- 혼자 미리 확인할 때: 에디터에서 방을 만들고, 같은 PC에서 `Builds/Win64/MurderMystery.exe`를 실행해 코드로 참가. 한 PC에서 마이크·스피커를 같이 쓰면 하울링이 나니 이어폰 사용.
- 접속은 Relay를 거치므로 같은 와이파이일 필요가 없다.
- 5명이 다 안 모여도 진행된다 (준비·투표는 들어와 있는 사람 기준).

## 3. 테스터에게 보낼 안내문 (복사용)

```
[윤 대감 댁의 마지막 밤 — 테스트 안내]

1) 받은 압축 파일을 풀고 폴더 안의 MurderMystery.exe 를 실행하세요.
   - "Windows의 PC 보호" 창이 뜨면: 추가 정보 → 실행
   - 마이크가 안 되면: Windows 설정 > 개인 정보 > 마이크 > "데스크톱 앱이 마이크에 액세스하도록 허용" 켜기
2) 아무 키를 누르고 [코드로 참가] → 제가 알려 드린 6자리 코드와 이름을 입력하고 [참가].
3) 원하는 인물을 고르세요 (다른 사람이 고른 인물은 선택 불가).
4) 이어폰 + 마이크 권장. 토론 단계에는 전체 음성, 조사 단계에는 밀담 상대와만 대화됩니다.

조작
  WASD 이동 / Shift 달리기 / 마우스 시점
  E  바라보는 곳 조사
  R  숨겨 둔 물건 회수
  Tab 수첩 (단서·질문·준비 완료·밀담·투표)
  Space 점프 (돌·문턱 정도)  /  C 앉기·일어서기 (움직이면 일어남)
  Esc 마우스 커서 풀기/잠그기

약속
  - 범인만 거짓말을 할 수 있습니다. 나머지는 숨길 수는 있어도 거짓말은 안 됩니다.
  - 내 시나리오북(인물 정보)은 다른 사람에게 그대로 보여 주지 마세요.

끊겼을 때: exe를 다시 켜고 같은 코드로 들어와 원래 인물을 고르면 이어서 할 수 있습니다.
```

## 5. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 코드로 참가 실패 | 호스트와 같은 빌드인지, 코드 오타(대문자), 호스트가 아직 방에 있는지 |
| 음성 안 들림 | 인물 선택 화면의 음성 상태 표시("음성 연결됨"인지), Windows 마이크 권한, 조사 단계에는 밀담 중에만 들림 |
| 인물이 선택 안 됨 | 이미 다른 사람이 고름 / 배역 선택이 끝난 뒤에는 원래 내 인물만 선택 가능 |
| 방 만들기 실패 | 인터넷 연결, Unity 대시보드에서 Relay가 켜져 있는지 |
