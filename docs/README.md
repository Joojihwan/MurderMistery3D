## 진상 한 단락

환갑잔치 낮, 윤 대감은 문중 앞에서 양자 입적·열녀 상소·장부 고발을 선언했다. 그러나 봄부터 시한부임을 알던 대감은 그날 밤 정반대의 문서 다섯 통을 썼다. 넷은 사람들을 풀어 주는 문서였고, 하나는 자기 비리까지 자백하는 고발장이었다.
서자 **윤재하**는 낮의 선언을 믿고, 이튿날 아침 양자 날인을 미루려 탕약에 쥐약을 조금 탔다. 죽일 생각은 없었으나 병으로 쇠약한 대감은 숨을 거두었다. 재하가 막으려던 "禮曹" 봉투는 사실 자신을 아들로 인정하는 청원서였다.

## 맵

![윤 대감 댁 배치도](design/map_layout.svg)

| 블록아웃 (위에서, 지붕 숨김) | 블록아웃 (남동쪽 조감) |
|---|---|
| ![top](design/blockout/blockout_top.png) | ![persp](design/blockout/blockout_persp.png) |

- 1 유닛 = 1m, 원점 = 대문 중앙, +X 동쪽, +Z 북쪽. 담장 48m × 50m.
- 중문 밖(바깥마당·행랑채)은 이동 불가. 조사는 중문 안 전역(사당 제외).
- 핵심 규칙: 마루에 오를 땐 섬돌에 신을 벗는다 → 마루 위 진신 자국 = 몰래 움직인 사람(변 행수).
- 블록아웃 씬은 `ManorBlockoutBuilder.cs`가 생성한다. 좌표 수정은 스크립트에서.
