# 사건 당일 타임라인 (마스터 전용 · 2단계)

> 상위 문서: [scenario_draft.md](scenario_draft.md) 진상 개요.
> 이 문서는 진실 그대로의 기록이다. 3단계 시나리오북은 이 표에서 각 인물이 **직접 보고 듣고 한 일만** 뽑아 1인칭으로 쓴다.

## 0. 추가 설정 (2단계에서 확정)

- 대감의 부인은 5년 전 사망. 맏며느리 정씨가 안주인 역할을 맡는다.
- 변 행수는 양반가 첩의 아들(서얼) 출신으로, 벼슬길이 막히자 장사로 일어섰다. 그래서 재하의 서자 차별 철폐 모임에 몰래 돈을 댄다.
- 정씨의 비밀 편지 상대는 친정 오라비. 집을 떠날 방도를 의논해 왔고, 편지는 분이가 문지기를 통해 전한다.
- 양자 입적(계후)과 승적은 모두 예조(禮曹)에 올리는 일이다. 그래서 겉봉에 "禮曹"라고만 쓰인 문서를 재하는 양자 입적 청원으로 오해한다.
- 분이는 글을 모르지만 정씨에게 배워 한글로 쓴 제 이름 "분이"는 알아본다.
- 체격: 재하는 키가 크고 호리호리하다. 허 의원은 작달막하다. 변 행수는 몸집이 크고 배가 나왔다. 밤에 남자들은 실내에서 갓을 벗는다 (그림자 목격 판별용).

## 1. 공간 (타임라인용 최소 정의, 맵 설계 때 확장)

```
[대문] ─ 바깥마당 ─ [행랑채: 문지기, 도 검률]
   │
[중문] ← 술시 초 안에서 빗장. 밤새 열리지 않음 (문지기 증언)
   │
 안쪽 ─┬─ 사랑채: 사랑방(대감 거처, 화로·소반) ─ 서재(서안·문갑) / 대청(마루) / 작은사랑(재하 방)
       ├─ 안채: 건넌방(정씨) / 안방(빈방) / 부엌·찬방(분이)
       ├─ 별당: 손님방 둘(허 의원, 변 행수) — 뒷간이 가까움
       └─ 곳간(쥐약 단지) / 장독대 / 우물
```

- 사랑방과 서재는 장지문 하나로 이어진다. 작은사랑은 대청을 사이에 두고 사랑방과 붙어 있어, 벽 너머 말소리와 큰 소리가 들린다.
- 별당과 안채에서 사랑채로 가려면 지붕 없는 마당을 건너야 한다. 비 오는 밤에는 신에 진흙이 묻는다. 작은사랑에서 사랑채 안으로 가는 길은 마루로 이어져 진흙이 묻지 않는다.
- 신발: 정씨 = 당혜(여인 가죽신), 분이 = 작은 짚신, 허 의원 = 짚신, 변 행수 = 진신(기름 먹인 비 오는 날 가죽신, 큰 자국), 재하 = 실내에서 버선.
- 예법: 방이나 마루에 오를 때는 섬돌에 신을 벗는다. 정상적인 방문은 섬돌에만 진흙을 남기고, 마루 위 신발 자국은 신을 벗지 않은 사람의 흔적이다. 상세 배치는 [map_layout.md](map_layout.md).

## 7. 목격·인지 매트릭스 (3단계 시나리오북의 원천)

각 인물이 **직접** 보고 듣고 한 일만 적는다. 시나리오북에 이 범위를 넘는 정보를 쓰지 않는다.

### 정씨
- 낮의 선언 (공통). 19:00 분이에게 중문 빗장을 지시.
- 22:00 분이에게 친정 오라비 앞 편지를 맡김.
- 22:50 탕약을 두고 빈손으로 돌아오는 분이를 창으로 봄.
- 23:20 사랑방에서 종이 탄 냄새. 탕약이 손대지 않은 채 소반에 있음.
- 23:30 대감이 자기 권유로 탕약을 반쯤 마심. "네 일은 이미 정해 두었다. 내일 아침이면 알게 될 게다."
- 서재 안을 들여다보지 않음. 05:30 비명, 05:35 빗장 확인.

### 윤재하 (범인)
- 낮의 선언 (공통). 20:10 대청을 서성이는 변 행수.
- 20:30 곳간에서 비상을 덜어 상소 초안 한 장에 쌈 (범행 준비). 20:35 분이에게 보였을 수 있음.
- 22:00 변 행수 방문, 장부 위치를 알려 줌, 상소 자금 이야기.
- 23:00 사랑방 탕약에 비상을 타고 종이를 화로에 던짐.
- 23:20~23:35 벽 너머 정씨와 대감의 대화. "내일 아침이면 알게 될 게다"를 양자 이야기로 들음.
- 00:30 서재의 쿵 소리. 나서지 않음.
- 00:48 대청을 지나는 작은 그림자와 치맛자락 소리.
- 01:00 서재에서 엎드린 아버지를 봄 (숨 확인 안 함). 禮曹 봉투를 가져와 서책 사이에 숨김.
- 01:30 무거운 발소리와 문갑 여닫는 소리.

### 분이
- 낮의 선언 (공통). 19:00 중문 빗장.
- 20:00 허 의원에게 바뀐 약첩을 받음. 20:35 곳간에서 기름병을 들고 나오는 재하.
- 22:00 정씨의 편지를 받아 저고리에 넣음.
- 22:45 탕약을 소반에 둠. 서재 안 대감 목소리와 붓 소리.
- 00:45 서재 잠입. 초가 거의 다 탔음, 대감은 엎드려 거친 숨. "분이" 봉투를 가져와 쌀독에 숨김.
- 05:30 시신 발견.

### 허 의원
- 낮의 선언 (공통).
- 19:30 진맥: 대감은 길어야 두어 달. 대감 "오늘 밤 할 일이 있네". 봄부터 대감의 부탁으로 병을 숨겨 옴.
- 19:50 처방 변경. 20:00 분이에게 약첩 전달.
- 22:20 변 행수가 돌아오는 기척.
- 01:45 젖은 채 숨을 몰아쉬며 돌아온 변 행수. "뒷간에 다녀왔소."
- 의학 지식: 은비녀가 엷게 변했다면 독의 양이 적다. 성한 사람이라면 죽을 양이 아니다.

### 변 행수
- 낮의 선언 (공통). 20:00 면담 거절당함.
- 22:00 재하에게 장부 위치를 들음.
- 23:05 뒷간에서 돌아오다 사랑방 불빛 앞을 지나는 그림자: 키 큰 사내, 갓을 안 씀.
- 01:30 서재 잠입: 대감은 이미 숨이 없고 손이 차가움. 장부와 官衙 봉투를 가져옴.
- 01:45 허 의원에게 "뒷간에 다녀왔소"라고 거짓말.

## 8. 정합성 체크

- [x] 탕약에 손댈 기회: 분이(달임), 허 의원(약첩), 재하(23:00), 정씨(23:20~23:35). 변 행수는 사발에 접근한 적 없음 (서재 잠입은 마신 뒤).
- [x] 사망 시각 좁히기: 분이(00:45 숨 있음) + 변 행수(01:30 숨 없음) 증언이 모두 나와야 01:00 전후로 좁혀짐. 둘 다 잠입을 숨기려 하므로 증언을 끌어내는 것이 과제.
- [x] 진흙 자국: 섬돌 진흙은 정상 방문(22:00 변 행수 작은사랑, 22:45·00:45 분이, 23:20 정씨). 마루 위 진신 자국은 01:30 변 행수가 신을 신은 채 서재로 간 것뿐. 재하는 작은사랑에서 마루로만 움직여 자국이 없음.
- [x] 촛불: 00:45 거의 다 탐 → 01:00 꺼짐 → 01:30 변 행수의 등롱. 재하가 아버지 상태를 못 알아본 이유.
- [x] 범인 특정 경로: C1(상소 종이) + C2(기름 방울) + 분이 목격(기름병) + 변 행수 목격(갓 안 쓴 키 큰 사내) + 적은 독의 양(허 의원) → 죽이려던 게 아니라 날인을 미루려던 사람 → 재하.
