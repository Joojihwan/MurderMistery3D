# 밸런스 검토 v1 (플레이테스트 전 분석)

> 2026-10-11. 규칙 코어(`GameSession`)로 무작위 플레이 2,000판 × 2가지 시나리오를 돌린 결과와 추리 경로 분석.
> 재현: `dotnet test Tools/OfflineTests/OfflineTests.csproj --filter BalanceSimulation` (Explicit 테스트).

## 1. 시뮬레이션 조건

- 5명이 차례로 1회씩 행동, 점수(라운드당 3점)가 바닥날 때까지 반복.
- 숨긴 물건 주인은 1차 조사에서 50% 확률로 회수(2점), 2차 조사에서는 먼저 회수.
- 나머지는 아직 다 보지 못한 지점 중 무작위 선택.
- **random**: 모두 무작위. **culprit-cleans-up**: 범인이 1차에 자기 물건 회수 + 화로 종이(C1)를 먼저 가져감.
- 사람 사이 정보 공유(토론·밀담)는 시뮬레이션하지 않음. "누군가 발견했는가"만 측정.

## 2. 결과 요약

| 단서 | random: 누군가 발견 | random: 범인 외 발견 | 청소 시나리오: 범인 외 발견 |
|---|---|---|---|
| 표층 흔적(N1, C2, C3a·b, N2, N3, C6, C8) | 87~89% | 81~83% | 82~84% |
| C3c 디딤돌 진흙 (지점 2곳) | 98% | 96% | 97% |
| C1 화로 종이 | 87% | 69% | **25%** |
| D1 査頓宅 / D2 許醫員 (같은 문갑) | 88% / **61%** | 70% / 49% | 76% / 48% |
| C5 처방전 | 87% | 70% | 75% |
| 숨긴 물건 H1·H3·H5·H6 | 100% (주인 포함) | 99% | 99% |
| **H4 禮曹 / C7 초안 (범인 소유)** | 100% (주인) | **0~4%** | **0%** |

라운드 1에 숨긴 물건을 회수하는 횟수는 한 판 평균 3.7~4.0회.

## 3. 해석

1. **표층 단서는 대부분 발견된다 (80%대).** 30회 행동으로 표층 지점 17곳을 거의 덮는다. 실제 플레이어는 무작위보다 효율적이므로 더 높을 것.
2. **범인의 심층 물건(禮曹 봉투·초안)은 사실상 다른 사람이 찾지 못한다.** 주인이 회수 우선권을 갖기 때문. → **추리가 C1↔C7 연결에 의존하면 안 된다.** 다행히 다른 경로가 있다 (4절).
3. **범인이 C1을 먼저 가져가면 물증 하나가 사라진다 (75% 성공).** 정상적인 범인 대응 전략이지만, 아무 흔적이 없으면 불공정하다. → **수정 완료**: 물건을 가져간 자리에는 항상 흔적이 남는다 (화로: "재를 헤집은 자국").
4. **D2는 61%만 발견.** 문갑에서 봉투 두 통을 다 가져가려면 두 번 살펴야 하기 때문. 허 의원의 소지 목표(2점)가 운에 크게 좌우될 수 있다. → 실제 플레이에서 허 의원은 목록(C4)을 본 뒤 노릴 수 있어 일단 유지, 플레이테스트에서 확인.
5. **공개 단서만 있는 지점(한약 사발)이 1점을 깎던 문제.** → **수정 완료**: 이미 모두 아는 것만 있는 지점은 무료.

## 4. 범인 특정 경로 점검 (물증이 사라져도 성립하는가)

| 경로 | 필요한 것 | 범인이 지울 수 있나 |
|---|---|---|
| A. 화로 종이 ↔ 초안 | C1 + C7 | **예** (둘 다 범인이 선점 가능) |
| B. 기름과 창고 | C2 + N3 + C3c(재하의 신에 마른 진흙) + 분이 증언(기름병 든 재하) | 아니오 (흔적·증언). 단, 재하는 "기름 가지러 갔다"는 그럴듯한 해명이 있음 |
| C. 독이 들어간 시간과 장소 | N2(달일 땐 독 없음) + 정씨 증언(23:20 손대지 않음, 23:30 마심, 종이 탄 냄새) → 독은 22:50~23:20 사이 사랑방에서 | 아니오. 정씨가 의심받을까 봐 증언을 숨길 수 있음 |
| D. 진흙 없는 침입자 | C3c(사랑방 앞 디딤돌엔 당혜·짚신뿐) + C의 시간대 → 마당을 건너지 않고 사랑방에 들어온 사람 = 사랑채 안에 사는 사람 | 아니오 |
| E. 그림자 | 변 행수 증언(23:05 키 큰 남자, 갓 없음) + 체격 | 아니오. 변 행수는 자기 행적(밤중 외출)을 드러내야 함 |
| F. 의도 (보너스) | E1(옅은 반응) + 허 의원 지식 또는 D2 | 아니오 |

→ 범인이 물증 A를 지워도 **B·C·D·E 중 두세 개를 맞추면 재하로 좁혀진다.** 각 경로가 "누군가 자기 비밀을 털어놓아야" 완성되도록 짜여 있어, 대화가 추리의 핵심이 된다. 의도한 구조와 맞다.

## 5. 위험 요소와 대응

| 위험 | 정도 | 대응 |
|---|---|---|
| 범인이 너무 쉽게 잡힘 (경로 B·D가 직접적) | 중 | 경로 B는 해명 가능하게 이미 설계됨. 플레이테스트에서 재하 지목률이 80%를 넘으면 C3c에서 "재하의 신" 표기를 "남자 신 한 켤레"로 흐린다 |
| 범인이 너무 어려움 (증언이 안 나옴) | 중 | 정씨·변 행수에게 증언할 동기가 약하면 개인 목표에 "진실을 밝힌다" 류 보조 목표 추가 검토 |
| 변 행수에게 의심이 쏠림 (서재 침입 흔적이 가장 강함) | 의도됨 | 사망 시각(분이 00:45 생존 + 변 01:30 사망)과 음독 시각(23:30)으로 해소 가능 |
| 허 의원 소지 목표가 운에 좌우 (D2 61%) | 저 | 플레이테스트 후 D1·D2를 한 번에 살필 수 있게 바꿀지 결정 |
| 15분 조사에 3행동 + 질문 2 + 밀담 2회가 빠듯 | 저 | 이동 거리 최대 약 50m, 걷기 2.2m/s 기준 30초 이내. 여유 있음 |
