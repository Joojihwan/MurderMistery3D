# 스토리 확장 v2 — 모두가 범인처럼 보이는 밤 (마스터 전용)

> 2026-10-16 사용자 요청: 잠긴 문과 열쇠, 단서 대폭 추가(의미 없는 단서 + 결정적이지만 바로 범인을 가리키지 않는 단서),
> 인물마다 지목될 만한 **결정적 증거와 행동**, 사인(死因)을 흐리는 요소.
> 진상(범인 재하, 비상 소량 + 시한부 몸)은 그대로 둔다. 새 사건은 모두 기존 타임라인과 어긋나지 않게 끼워 넣었다.
> 원칙: 오리지널 창작. 범인이 아닌 사람은 거짓말을 못 하므로, 오해는 **사실이지만 오해하기 쉬운 물증**으로 만든다.

## 7. 균형

- 조사 점수 단계당 3 → **4점** (5명 × 2단계 = 40회). 지점은 35곳 + 잠긴 곳.
- 범인 특정 최소 경로는 그대로 (clues.md "추리 경로 검증"). 새 단서는 경로를 막지 않는다.
- 재하에게 불리한 새 물증은 X4 하나뿐이고, 주인이 모호하며 2차 조사(심층)에서만 나온다. 대신 정씨·분이·허·변 각자에게 1차에 바로 보이는 의심 물증이 생겨 초반 의심이 분산된다.
