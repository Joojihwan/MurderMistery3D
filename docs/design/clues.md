# 단서 배치표

> 상태: 초안 (2026-10-11). 진실 근거는 [timeline.md](timeline.md). 규칙은 [game_rules.md](game_rules.md) 3절.
> 이 문서가 단서의 최종 목록이다 (timeline.md 6절의 ID를 대체·확장).

## 표기

- 층: 표층 = 1차 조사부터 / 심층 = 2차 조사부터 (숨긴 본인은 1차부터 2점으로 회수)
- 유형: 흔적(살핀 사람 모두 앎, 소지 불가) / 물건(1명 소지)
- `exposes`: 공개되면 실패하는 비밀 목표

## 공개 물증 (초검 발표, 전원 자동 획득)

| ID | 내용 |
|---|---|
| E1 | 사랑방 소반의 탕약 사발, 반이 남음. 은비녀가 **엷게** 검어짐 |
| E2 | 대감은 서재 서안에 엎드려 숨짐. 붓이 떨어져 있음 |
| E3 | 서재 촛대의 초가 끝까지 타서 꺼짐 |
| E4 | 검시 추정 사망 시각: 사경 무렵 (축시, 01~03시) |
| E5 | 중문 빗장은 안에서 걸려 있었음. 문지기: 밤새 중문을 연 사람 없음, 도 검률은 해시에 도착해 행랑채에서 잠 |

## 추리 경로 검증

- 범인 특정에 필요한 최소 조합: (C1 + C7) 또는 (C2 + N3 + 분이 증언) 중 하나 + (N2: 독은 사랑방에서) + (변 행수의 그림자 증언 또는 체격 추론).
- 의도(보너스 문항) 추론: E1(엷은 반응) + 허 의원 지식 또는 D2(시한부) → 적은 양으로도 죽을 몸 → 죽이려던 게 아니다.
- 범인이 아닌 네 사람 모두에게 의심받을 단서가 있다: 분이(달인 사람, H1), 허 의원(C5 처방 변경, C6 비상), 정씨(탕약을 권함, 당혜 자국), 변 행수(C3a·C3b·C8, H5).
